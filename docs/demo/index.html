自己验证一遍（约 20 秒）

  1. 按 F12 打开开发者工具，切到 Network（网络）标签
  2. 点一下 清空（禁止符号），把已有记录清掉
  3. 回到这里，点 「一键填入」
  4. 看 Network 面板 —— 一条新记录都不会出现
为什么这一下能证明？因为「把信息发出去」这个动作，在浏览器里**必然**会留下一条网络记录。 只要一条都没有，就说明数据没有离开这台机器。

这也是 OpenWangShen 与「云端自动填写工具」的根本区别 —— 后者要把你的值传给它的服务器才能算出该选哪一项，代价是你的数据必须出本机。

三条红线（与正式程序一致）：① 绝不点提交 ② 绝不填密码、不碰验证码 ③ 身份信息不出本机

本页为纯静态演示，不含任何外部依赖、不加载任何第三方脚本。填入所用数据全部为虚构。
