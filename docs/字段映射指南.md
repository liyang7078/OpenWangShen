# 字段映射指南

> 字段识别的准确率，直接决定这个工具有多好用。
> **规则库是可以被任何人扩写的纯 JSON 文件** —— 这是最容易参与的贡献方式。

---

## 一、规则库长什么样

文件：`assets/字段规则_通用.json`

```json
{
  "_说明": "元数据，以下划线开头的键程序会跳过",
  "字段": [
    {
      "键": "手机号",
      "标签": ["手机号", "手机号码", "联系电话", "电话", "移动电话", "Mobile", "Phone"],
      "必填": true,
      "类型": "text",
      "分组": "联系方式"
    }
  ]
}
```

### 各字段含义

| 键 | 必填 | 说明 |
|---|---|---|
| `键` | ✅ | **档案 JSON 里的键名**。同一键只能出现一次 |
| `标签` | ✅ | 页面上可能出现的所有写法。匹配时按这些标签建索引 |
| `必填` | ✅ | 影响体检报告的「必填项缺失」判定 |
| `类型` | ✅ | 见下表 |
| `分组` | ✅ | 影响体检报告的分组统计与清单排序 |

### 类型取值

| 类型 | 填写方式 |
|---|---|
| `text` | 直接填入文本 |
| `textarea` | 长文本 |
| `number` | 数字 |
| `date` | 日期，自动归一为 `YYYY-MM-DD` |
| `select` | 下拉框，按选项文本匹配，退化按 value 匹配 |
| `radio` | 单选，按选项文本匹配 |
| `checkbox` | 复选 |
| `file` | **附件** —— 键名必须以 `附件_` 开头 |

### 分组取值

`基本信息` / `联系方式` / `教育背景` / `能力证书` / `求职意向` / `经历与自述` / `附件`

## 二、匹配是怎么做的

`core.map_one()` 的两级策略：

### 一级：精确匹配

标签**归一化后完全相等**。

归一化做的事：
1. 去掉 `*`（必填星号）、冒号、逗号、问号、感叹号、连字符
2. 去掉括号及括号内容：`姓名（中文）` → `姓名`
3. 去掉所有空白（含全角空格）
4. 转小写：`Full Name` → `fullname`

所以 `姓名*`、`姓名（中文）`、`姓 名` **都会**匹配到 `姓名`。

### 二级：包含匹配

页面标签与规则标签**互为子串**时命中。多个候选取**标签最长**的（最具体）。

### 防误命中

- 页面标签归一化后**长度 < 2 时不参与模糊匹配**
  （否则一个「名」字会撞上「紧急联系人姓名」）
- 规则标签长度 < 2 时同样不参与

## 三、怎么补一条规则

### 场景

你在某个页面看到字段叫「**联系人手机**」，没被识别出来。

### 步骤

1. 打开 `assets/字段规则_通用.json`
2. 找到 `"键": "手机号"` 那一条
3. 把新标签加进 `标签` 数组：

```json
{
  "键": "手机号",
  "标签": ["手机号", "手机号码", "联系电话", "电话", "移动电话",
           "联系人手机", "Mobile", "Phone", "Phone Number"],
  ...
}
```

4. 跑测试确认没改坏东西：

```bash
python scripts/wangshen.py selftest
python -m unittest discover -s tests
```

### 如果是全新的字段

在 `字段` 数组里**追加**一条（不要插在中间，避免打乱原有顺序）：

```json
{
  "键": "作品集链接",
  "标签": ["作品集", "作品链接", "Portfolio", "Portfolio URL"],
  "必填": false,
  "类型": "text",
  "分组": "经历与自述"
}
```

同时记得在 `fixtures/档案_示例.json` 里也加上这个键（保持示例完整）。

## 四、附件的特殊约定

**键名以 `附件_` 开头**的字段会被特殊处理：

1. 不参与「档案必填缺失」判定（因为附件是**文件**，不存放在档案 JSON 里）
2. 在填写清单里单独归入「附件」节，不混进填表表格
3. 在自动填表时一律判为**人工门**（需要人从本机选文件）

```json
{
  "键": "附件_简历",
  "标签": ["简历", "上传简历", "个人简历", "Resume", "CV", "Upload Resume"],
  "必填": true,
  "类型": "file",
  "分组": "附件"
}
```

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 同一 `键` 出现两次 | 后者被忽略，行为诡异 | 合并成一条，标签并进同一个数组 |
| `键` 名与档案里写的不一致 | **该项永远填不上** | `check_profile.py` 会报「档案未登记字段」，据此排查 |
| 附件类没加 `附件_` 前缀 | 被当成普通文本字段，填不进去 | 加上前缀 |
| 标签写得太宽泛 | 误命中别的字段 | 用具体写法，如「手机号码」而非「号码」 |
| 用了 `-` 做标签分隔（如 `CET-4`） | 归一化时 `-` 会被去掉 | 没问题，两边都会去，仍能匹配 |
