# 快速开始

> ⚠️ **本工具是独立功能，用之前有三件事必须先做：**
>
> 1. **自己完成注册** —— 它不代你注册，也不要你的账号
> 2. **自己完成登录** —— 它不绕登录，也不帮你过人机验证
> 3. **进到「填写简历信息」那个页面之后再运行** —— 它扫描的是**当前打开页面**上的表单
>
> 停在登录页 / 首页 / 岗位列表页上跑，只会打印「发现 0 个输入控件」。

---

## 0. 环境

| 功能 | 需要 |
|---|---|
| 档案体检 / 填写清单 / 脱敏 | **Python 3.8+**（只用标准库，无需 pip） |
| 自动填表 | 额外需要 `playwright` |

```bash
pip install playwright
playwright install chromium
```

> 如果没有 `playwright`，自动填表会自动降级到「填写清单」模式，**不会报错崩溃**。

---

## 1. 准备你的档案

**顺序不能反：先有清单，再有档案。**

### 1.1 先出空白问卷（这一步别跳）

```bash
python scripts/wangshen.py checklist --out 网申信息清单.md
```

它把「网申会问到的字段」按词表现算成一张空白问卷（必填 12 / 常用 24 / 其余选填 116，
另加 11 组记录组）。**清单没填，就没有档案；没有档案，后面每一步都无从谈起。**

> 这份问卷是**空白**的 —— 不含你任何既有信息，所以可以放心交给 AI 陪你逐项过。

### 1.2 有现成简历？让它先替你抽一遍

```bash
python scripts/wangshen.py resume --in 我的简历.docx
```

在**本机**把简历读成文本、按规则抽出字段，写成 `profile.json`：

- 抽到的 → 直接填好
- 抽不到的 → 留着「待补」，你再照问卷补

**全程不联网、不调模型。** 抽出的键名一律取自词表，保证后面填表时一定取得回来。

> `.txt` / `.md` 零依赖；`.docx` 需 `python-docx`，`.pdf` 需 `pdfplumber` 或 `pypdf`。
> 缺库时它会**明确告诉你要装什么**（也可以先把简历另存为 `.txt`）。

### 1.3 或者从示例档案起手

```bash
cp fixtures/档案_示例.json profile.json
```

然后用任意文本编辑器打开 `profile.json`，把示例值换成你自己的：

```json
{
  "姓名": "张三",
  "性别": "男",
  "出生日期": "1999-01-01",
  "手机号": "13800000000",
  "电子邮箱": "zhangsan@example.com",
  "身份证号": "110101199901011234",
  "最高学历": "硕士研究生",
  "毕业院校": "某某大学",
  "专业": "会计学",
  "毕业时间": "2026-06"
}
```

> ⚠️ **`profile.json` 只放在本机，不要提交到 Git。** `.gitignore` 已屏蔽该文件名。

## 2. 体检

```bash
python scripts/wangshen.py check --profile profile.json
```

输出会告诉你：

- 每个分组的填写进度（用进度条直观显示）
- 哪些字段还缺（并标注必填 / 选填）
- 档案里有没有拼错的键名（这类错误会导致该项**永远填不上**）
- 需要准备的附件清单

```
【分组覆盖】
  基本信息      ████████████  12/12
  联系方式      ███████······   5/7
  教育背景      ██████████···  10/12
  ...
【结论】
  ✅ 必填项齐全。
```

## 3. 预演（强烈建议）

先看这个页面能不能识别，**不写入任何内容**：

```bash
python scripts/wangshen.py fill --profile profile.json \
    --url "https://某公司招聘页" --dry-run
```

输出类似：

```
[1/5] 打开页面：https://...
[2/5] 扫描表单字段
      发现 26 个输入控件
[3/5] 映射结果：可填 22 ／ 档案缺项 0 ／ 人工门 4 ／ 未命中 0
[4/5] --dry-run：不写入任何内容
[5/5] 未指定 --screenshot
```

**看第 3 行的四个数字**：

| 指标 | 含义 | 怎么办 |
|---|---|---|
| 可填 | 能自动填的字段数 | 越多越好 |
| 档案缺项 | 页面要、但你档案里没有 | 补进档案即可长期复用 |
| 人工门 | 密码/验证码/附件 —— **程序不碰** | 你自己来 |
| 未命中 | 页面有、但规则库不认识 | 手填，或补规则库 |

## 4. 正式填

```bash
python scripts/wangshen.py fill --profile profile.json \
    --url "https://某公司招聘页" \
    --screenshot filled.png \
    --out 填表报告.json
```

程序会：

1. 打开页面
2. 识别字段
3. 从档案取值写入
4. **回读一遍核对**（写进去又被页面丢掉的，会从「已填」里剔除）
5. 截图
6. **停下**

**它不会点提交。** 你去看截图，确认无误后自己点。

### 页面要求登录？（真实网申站几乎都要求）

裸开浏览器只会停在登录页 —— 一个字段都扫不到。正确做法是**复用你自己登录好的浏览器**：

```bash
# ① 开一个「可被接管」的浏览器（独立配置目录，不动你日常浏览器）
python scripts/wangshen.py browser

# ② 在弹出的窗口里，你自己登录，走到「填写简历」那一页
#    （登录这件事程序不参与，也拿不到你的账号密码）

# ③ 让程序接管这个浏览器
python scripts/wangshen.py fill --profile profile.json \
    --url "https://某公司招聘页" --connect 9222
```

程序会**优先复用你当前那个页签**（不新开标签、不刷掉你已经填的内容），
跑完只断开连接，**不关你的浏览器**。

### 单站 300 秒预算

默认每站最多跑 **300 秒**（`--budget`，`0` = 不限）。到点、或**识别率低于 20%**、
或**一个控件都没扫到**、或**没有任何字段能自动填**，它会**自己停手**，不再往下填：

```
[预算] 本站上限 300 秒 —— 到点即停手，转「可复制清单页」
      ⚠️ 识别率过低（13%，低于 20%）—— 停手，不再往下填
```

这不是失败，是**提前止损**。与其在一个不认的表单上耗到底，不如把已经拿到的交给你。
加 `--html 填写清单.html`，停手时会**直接生成那张可复制页**。

退出码：`0` = 正常跑完 ｜ `2` = 参数/网址被拒 ｜ `4` = 缺 playwright ｜ `5` = 提前停手。

> **网址会被检查**：只接受 `http` / `https` 的公网站点。
> `file://`、`javascript:`、内网 IP 一律拒绝 —— 因为程序要往这个页面里
> **写你的真实信息**，不能写进一个来路不明的地方。

## 5. 打不开页面？

### 先查代理

Chromium 系浏览器（Chrome/Edge）**不读 `HTTP_PROXY` 环境变量**，
必须显式传参。这是「浏览器打不开、但 `curl` 正常」的最常见原因：

```bash
python scripts/wangshen.py fill --profile profile.json \
    --url "https://..." --proxy http://127.0.0.1:7890
```

### 还是不行？用清单模式

```bash
python scripts/wangshen.py sheet --profile profile.json \
    --company "某集团" --job "财务会计岗" \
    --labels-file 页面字段.txt --out 填写清单.md
```

`页面字段.txt` 每行一个字段名（从页面上抄）。没有该文件也行 ——
程序会按规则库列出全量字段，必填优先。

生成的清单长这样：

| # | 页面字段 | 填写内容 | 必填 |
|---|---|---|---|
| 1 | 姓名* | 张三 | ✔ |
| 2 | 手机号码* | 13800000000 | ✔ |

你对着往网页里粘即可。

### 再进一步：生成「可复制清单页」

对着 markdown 表抄还是容易抄错，渲染成一张本机网页会稳得多：

```bash
python scripts/wangshen.py sheethtml --in 填写清单.md
```

得到一个 HTML 文件，用浏览器打开：

- 每一项右边一个「**复制**」按钮 —— 点一下，粘到网页对应框里
- 底部一个「**复制全文**」按钮 —— 一次拿全部
- 大字号、高对比，长时间对着屏幕也不费眼

也可以一步到位（从档案现算，不必先生成 md）：

```bash
python scripts/wangshen.py sheethtml --profile profile.json --labels-file 页面字段.txt
```

> ⚠️ 这张页**含你的真实信息**，`.gitignore` 已屏蔽 `填写清单*.html`。别改名、别外发。

## 6. 需要 AI 帮你写开放题？

先脱敏，再发出去：

```bash
# 脱敏
python scripts/wangshen.py mask --profile profile.json \
    --in 草稿.txt --out 脱敏稿.txt

# 把「脱敏稿」发给 AI，拿到回复后还原
python scripts/wangshen.py mask --profile profile.json \
    --in AI回复.txt --out 还原稿.txt --restore
```

脱敏后会自动二验：再扫一遍确认真值无残留，未通过则拒绝输出。

## 7. 有个框就是填不上？

先跑一下：

```bash
python scripts/wangshen.py report
```

它会问你几个问题（框叫什么 / 哪个系统 / 该对应哪项 / 什么结果），然后输出一段
**可以直接粘贴成 Issue** 的文本，并自动带上环境信息。

**你不用自己想格式。** 而且输出与写盘前都会跑一次零真值反证 —— 命中手机号 /
邮箱 / 身份证 / 本机绝对路径就**中止**（既不打印也不写盘）。

提交地址它也会一并打印。你提一次，下一个遇到同一控件的人就不用再摸一遍。

## 常见问题

**Q：`--dry-run` 和正式填有什么区别？**
只差第 4 步：一个不写入，一个写入。扫描和映射逻辑完全一样。

**Q：为什么「人工门」里既有密码框又有附件？**
因为它们有共同点：**程序无从知道该填什么**。
密码只有你知道；附件要从你电脑里选哪一份，也只有你知道。

**Q：日期填成了 `2026-07-01`，但我档案里写的是 `2026-07`？**
日期控件需要完整日期，程序自动补了 `-01`。**这类补全会单独提示「请核对」**。
如果补错，你自己改一下即可。

**Q：能填多少个字段？**
取决于页面用了多少标准 HTML 表单控件。规则库当前覆盖 **165 个字段**
（152 个可填值字段 + 13 类附件）、**643 种标签写法**。未命中的字段会被如实列出，**不会瞎猜**。

**Q：填错了会怎样？**
不会怎样 —— 因为你还没提交。这也是「永不代提交」这条红线的价值所在。

**Q：支持哪些招聘系统？**
任何标准 HTML 表单都可以尝试。已实测可打开：
中国移动招聘站、北森门户、Moka。字段识别效果取决于标签是否在规则库中。

**Q：跑起来说「发现 0 个输入控件」？**
多半是**页面还没走到表单**。先完成注册 / 登录，进到「填写简历信息」那一页再运行 ——
本工具只看**当前页面**上的表单，不会替你点按钮往下走。这是设计如此，不是缺陷。
