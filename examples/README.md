# 示例产物

本目录存放工具跑出来的示例输出，供你对照参考。

| 文件 | 由谁产出 | 说明 |
|---|---|---|
| `填写清单_示例.md` | `make_sheet.py --selftest` | 保底模式的对照清单。含虚构个人信息 |
| `填表报告_示例.json` | `fill_form.py` | 自动填表的执行报告。**只含字段名与状态，不含真实值** |

## 怎么看这两份文件

**`填写清单_示例.md`** —— 重点看结构：

- 第一节：就绪的字段（你照着往网页里粘）
- 第二节：档案里没有、需要你补的
- 第三节：需要上传的附件（单独成节，不混进填表表格）
- 第四节：填完之后要做什么

**`填表报告_示例.json`** —— 重点看 `人工门` 数组：

```json
"人工门": [
  { "label": "上传简历*", "key": "附件_简历", "reason": "附件上传" },
  { "label": "验证码*",   "key": null,        "reason": "疑为验证码" },
  { "label": "登录密码",  "key": null,        "reason": "密码框" }
]
```

这三类字段程序**一律不碰**。它们的共同点是：**程序无从知道该填什么**。

## 数据说明

本目录下所有示例数据均为虚构（`fixtures/档案_示例.json`），
不对应任何真实自然人。你可以放心查看。
